BMS Training Tool
==================

beatorajaのプレイ実績から今の実力に合った練習曲を毎日提案するツールです。
ブラウザで動きます。

BMS Training Toolを開く: https://tinyurl.com/bms-training-tool


使い方
------
上のURLをChromeかEdgeで開いてください(FirefoxやSafariはフォルダ読み込みと
コントローラー連携に必要なAPIに対応していないため動作しません)。

初回は「フォルダを選択」からbeatorajaをインストールしたフォルダ
(beatoraja.exeがある場所)を選びます。ブラウザから「フォルダへのアクセスを
許可しますか」という確認が出るので、許可してください。あとは自動で
プレイヤー情報を読み込み、今日のおすすめ3曲が表示されます。次に開いた
ときも前回の続きから自動で再開します。

読み込んだデータはブラウザ内(IndexedDB)に保存されるだけで、どこにも
送信されません。


できること
----------
- Satellite / Stella・発狂BMS難易度表・Scramble難易度表の7key譜面から、
  テーマ(ガチ押し/中速/高速/ディレイ/おまかせ)ごとに3曲提案
  ※「中速」はBPM130-165付近の曲を優先しますが、ガチ押し/ディレイ/高速
    (BPM180以上)のどれにも当てはまらない曲は消去法で中速に含まれるため、
    実際にはBPMの幅が比較的広い曲が選ばれることがあります

- 同じ条件なら、未プレイ→Failed→Easy→…の順に練習の必要度が高い曲を
  優先して選ぶ。さらに同条件ならプレイ回数が少ない曲を優先する

- 自分のクリアランプから「そろそろ全滅し始めるレベル(上限)」を検出し、
  1曲プレイするたびにその上限に向けて自動でレベルを上げていく。上限は
  自分で固定することもできる

- レベルを上げる頻度は「レベルアップ幅」で調整できる(既定は1曲で1レベル。
  2曲で1レベル、1曲で2レベルなども選べる)

- 1曲プレイ後、自動で次の3曲を表示。無駄なクリック操作がありません

- 打鍵数・スクラッチ回数の記録とカレンダー表示。PHOENIXWAN /
  INFINITASコントローラーはWebHIDで直接読み取り、それ以外はGamepad API
  経由で計測

- 日本語 / English / 한국어 切り替え


困ったとき
----------
- 「beatorajaのフォルダが見つかりません」と出る
  → 選んだフォルダにsongdata.dbがあるか確認してください。beatorajaで
    一度もプレイしていないと検索できません

- 打鍵数が反応しない
  → 画面上部のコントローラー表示を確認してください。他のソフトが
    コントローラーを専有していないかも確認してください

- フォルダ選択やコントローラー接続のボタンが動かない
  → Chrome/Edgeの最新版で開いているか確認してください

- 曲数が少ない/特定の曲が全然出てこない
  → このツールは、最初に選んだbeatorajaフォルダの中に譜面データ
    (.bms/.bme等)があることを前提に解析しています。beatorajaの設定で
    譜面フォルダをインストール先以外(別ドライブ等)に置いている場合、
    そのフォルダをブラウザが直接読めないため候補から外れます。
    「譜面フォルダを追加で選択」からそのフォルダを追加で許可すると
    解決することがありますが、フォルダ名の一致で探す簡易的な仕組みの
    ためうまく検出できないケースもあります。改善しない場合は、譜面
    データそのものをbeatorajaフォルダの中に移動するのが一番確実です


データについて
--------------
選曲には以下の難易度表データを使っています。譜面ファイルそのものは配布
しておらず、手元のbeatorajaフォルダをブラウザから直接読むだけです。

- Satellite (https://stellabms.xyz/sl/) / Stella
  (https://stellabms.xyz/st/)
- 発狂BMS難易度表 (https://mirai-yokohama.sakura.ne.jp/bms/)
- Scramble難易度表 (https://egret9.github.io/Scramble/)

このほか、「ガチ押し」「ディレイ」テーマの選曲精度を上げる参考データとして、
以下の難易度表も取り込んでいます。BPMやノーツパターンからの自動分類だけ
では拾いきれない曲を、これらの表への掲載を手がかりに優先的に拾い
上げています。

- ウーデオシ小学校難易度表
  (https://lets-go-time-hell.github.io/Arm-Shougakkou-table/)
  (ガチ押し系の参考)
- ディレイjoy (https://lets-go-time-hell.github.io/Delay-joy-table/) /
  Delay小学校難易度表 (https://wrench616.github.io/Delay/)
  (ディレイ系の参考)

難易度表のデータは web/scripts/update-tables.js で取得し、GitHub Actions
で毎日自動更新しています。


開発
----
    npm install
    npm run web:build   (web/dist にビルド)
    npm run web:serve   (http://localhost:8080 でローカル確認)

デプロイはGitHub Actions経由でGitHub Pagesへ自動で反映されます。


安全性について
--------------
exeのダウンロードは不要で、ブラウザで開くだけです。プレイ実績やフォルダの
中身は外部に送信されず、全部ブラウザの中(IndexedDB)に保存されるだけです。
通信するのは難易度表のデータ(公開されている曲名・難易度の一覧)だけです。

読み込めるのは選んだフォルダの中だけで、書き換えや削除はしません(読み取り
専用)。許可はブラウザのサイト設定からいつでも取り消せます。
